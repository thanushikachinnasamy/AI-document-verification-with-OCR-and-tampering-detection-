AI Document Verification with OCR and Tampering Detection

AI-powered Document Verification System built using React, FastAPI, MongoDB, OCR, and Machine Learning to automate document validation, text extraction, and tampering detection.

Features

- User Authentication
- OCR-Based Text Extraction
- Document Upload & Verification
- AI-Powered Tampering Detection
- Image Quality Analysis
- Document Validation
- Real-Time Verification Results
- Fraud Detection Alerts
- Analytics Dashboard
- Downloadable Verification Reports

Activate Virtual Environment

Run Backend

uvicorn backend.main:app --reload

Run Frontend

npm start
